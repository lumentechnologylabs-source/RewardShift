# RewardShift — Protocol Changelog

**Version:** 0.1

**Purpose:** Track substantive changes to RewardShift research protocols and experimental methodology.

## 1. Purpose

This changelog preserves a chronological record of methodological decisions, revisions, and corrections affecting RewardShift research.

It complements Git version history by explaining why research procedures change and how those changes may affect experimental interpretation, reproducibility, and comparability.

This document does not replace experiment-specific protocols or ordinary software version control.

## 2. Change Categories

- **Established:** A new research protocol or methodological standard is introduced.
- **Amended:** An existing protocol or experimental procedure is modified.
- **Corrected:** An error in a protocol, implementation, or research record is identified and addressed.
- **Deprecated:** A previously used method is retired or superseded.
- **Clarified:** Documentation is improved without intentionally changing experimental procedures.

Each substantive entry should include the date, affected documents, version changes, reason, experimental status, and implications for existing results.

**Description**

To create a consistent, transparent research framework before conducting formal Level 2 experimental runs.

**Impact on existing results**

**Next action**

Review and adopt the standing protocols, then finalize and commit the Level 2 experimental protocol before formal data collection.
